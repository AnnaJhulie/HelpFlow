# HelpFlow

Um sistema simples de gerenciamento de chamados desenvolvido em **Python** durante meus estudos de programação.

O projeto foi criado para praticar conceitos de Python e, ao mesmo tempo, construir algo que pudesse ser usado como um projeto de portfólio.

## Funcionalidades

* Criar chamados
* Listar chamados
* Resolver chamados
* Excluir chamados resolvidos
* Gerar um ID para cada chamado
* Salvar os chamados em um arquivo JSON
* Carregar os chamados salvos ao iniciar o programa
* Confirmar antes de excluir um chamado
* Validar algumas entradas do usuário

## Tecnologias

* Python
* JSON

## Como funciona

O HelpFlow permite gerenciar chamados por meio de uma interface gráfica simples e intuitiva.

1. **Abrir chamado:** informe o título e a descrição do problema.
2. **Ver detalhes:** selecione um chamado para consultar suas informações.
3. **Resolver chamado:** altere o status para “Resolvido” quando o problema for solucionado.
4. **Excluir chamado:** remova chamados que já foram resolvidos, após confirmar a exclusão.
5. **Salvar dados:** os chamados são armazenados em um arquivo JSON, permitindo que continuem disponíveis ao reabrir o programa.
